# ООО «Обувь»

Учебное приложение на WPF для демонстрационного экзамена, вариант БУ.

## Запуск

1. Откройте `WpfApp1.sln` в Visual Studio с рабочей нагрузкой «Разработка классических приложений .NET» и пакетом разработки .NET Framework 4.7.2.
2. Восстановите пакеты NuGet для решения.
3. Запустите приложение клавишей F5.

## Вход

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin1` | `demo-admin1` |
| Менеджер | `manager1` | `demo-manager1` |
| Клиент | `client1` | `demo-client1` |

Гость может просматривать каталог без регистрации. Менеджеру доступны поиск, фильтр, сортировка и список заказов. Администратор также может добавлять, редактировать и удалять товары и заказы.

Исходная база находится в `Data/Shop.sqlite`. При сборке она копируется в каталог программы. Учётные записи в публичной версии вымышленные. У заказа № 7 дата заказа оставлена пустой, поскольку в исходной таблице указано `30.02.2025`.
